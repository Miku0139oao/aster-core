# Downloads

Download Aster Core binaries and native packages from [GitHub Releases](https://github.com/Miku0139oao/aster-core/releases).

Choose the asset that matches your operating system and CPU architecture. On older x86-64 CPUs, prefer names that include `amd64-v1` or `amd64-compatible`.

After you download a file, compare its SHA-256 with the checksum published on the same release. Then continue with [Quick start](/en/guide/getting-started) or [Your first proxy profile](/en/tutorials/first-proxy).
